# Java Object-Oriented Programming Practicals & MiniBank Project

This repository contains the weekly Java OOP laboratory practicals (Weeks 1 through 14) and the complete **MiniBank** Capstone Project developed through Milestones 1, 2, and 3.

## Directory Structure
- [`week_1/`](file:///d:/JAVA_OOP/JAVA_practicals/week_1) to [`week_12/`](file:///d:/JAVA_OOP/JAVA_practicals/week_12): Weekly OOP laboratory tasks covering syntax, OOP, interfaces, annotations, reflection, exception handling, multithreading, concurrency, NIO.2, and collections.
- [`week_13/`](file:///d:/JAVA_OOP/JAVA_practicals/week_13): Generic containers (`Box<T>`, `Pair<A,B>`), bounded type statistics (`<N extends Number> average`), and generic array-backed `SimpleStack<T>`.
- [`week_14/`](file:///d:/JAVA_OOP/JAVA_practicals/week_14): Tiny layered application, unit testing with `@Test`, modular package architecture, runnable JAR packaging, and serialization persistence.
- [`mini_project/`](file:///d:/JAVA_OOP/JAVA_practicals/mini_project): The complete MiniBank capstone application.
  - [**mini_project/README.md**](file:///d:/JAVA_OOP/JAVA_practicals/mini_project/README.md): Detailed capstone architecture, design patterns, testing, and execution guide.
  - [**mini_project/PROJECT_REPORT.md**](file:///d:/JAVA_OOP/JAVA_practicals/mini_project/PROJECT_REPORT.md): Formal project report and technical specification.

## Quick Start (MiniBank Capstone)

### 1. Run Unit Tests (@Test)
```powershell
java -cp mini_project/out BankServiceTest
```

### 2. Run Application (Executable JAR)
```powershell
java -jar mini_project/MiniBank.jar
```
